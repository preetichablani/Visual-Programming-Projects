# Visual-Programming-Projects

Overview

This repository contains 20 Visual Basic .NET (VB.NET) assignments developed as part of the Visual Programming course.
These projects cover Windows Forms applications, GUI controls, event-driven programming, database operations, and practical application development.

---

Technologies Used

- Visual Basic .NET (VB.NET)
- Windows Forms
- Visual Studio
- Microsoft Access / SQL Database
- .NET Framework
